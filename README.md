# stickersTelegramBot
Телеграм бот который генерирует стикеры из присланного текста

## 🚀 Быстрый старт

### 1. Предварительные требования
*   Установленный [Node.js](https://nodejs.org/) (версия 14 или выше).
*   Токен для Telegram Bot API. Получить его можно у [@BotFather](https://t.me/botfather).

### 2. Установка

 Клонируйте репозиторий (если вы его еще не склонировали)
 
```
git clone https://github.com/dudliy/stickersTelegramBot.git
cd stickersTelegramBot
```

# Установите необходимые зависимости
```
npm install
```

### 3. Настройка
Создайте файл .env в корневой папке проекта.

Добавьте в него ваш токен бота:

```
TOKEN=ВАШ_ТОКЕН_БОТА_ЗДЕСЬ
```

### 4. Запуск


```
node stickers-bot.js
```

При успешном запуске в консоли появится сообщение Бот запущен и работает....

### 🛠 Использование

Найдите вашего бота в Telegram.

Начните отправлять ему сообщения.

Бот автоматически сгенерирует стикер и отправит его вам.

Готово! Вы получите стикер из текста.

### ⚙️ Технические детали
Бот автоматически загружает и конвертирует стикеры в формат webp.

Изображение временно сохраняются в папку с ботом.

После отправки коллажа стикер очищается.
